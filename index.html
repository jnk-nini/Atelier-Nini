    03 Process

    Four fittings.

    The same four steps, whatever the size of the project.

    1. 01

      Measure

      Understand the real problem and who it is for before touching any code.

    2. 02

      Draft

      Plan the screens and the data first, so we agree on the shape before I build.

    3. 03

      Construct

      Smallest useful version first, then features added in small, tested steps.

    4. 04

      Finish

      Details, speed, phones and accessibility, until nothing is there by accident.

    04 About

    Soft on the surface, sharp underneath.

    I'm Jenny Joy, but everyone calls me Nini. I'm a third-year Computer Science student specialising in Software Engineering, and I like building things that are pretty and properly made.

    I learn fast and I notice the small things: the empty state nobody designed, the query that runs twice, the button that is two pixels off. Most of what I ship is tested, documented and deployed, because a project that only runs on my laptop is not finished.
